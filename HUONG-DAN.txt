APP THU CHI V10.2 PWA

Cách đưa lên GitHub Pages miễn phí:
1. Tạo repository mới trên GitHub, ví dụ: tai-chinh.
2. Upload TOÀN BỘ 5 file trong thư mục này vào nhánh main:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
3. Vào Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root), rồi Save.
6. Chờ GitHub tạo địa chỉ https://TENBAN.github.io/tai-chinh/
7. Mở địa chỉ đó trên điện thoại.
8. Android Chrome: menu ⋮ > Add to Home screen / Install app.
   iPhone Safari: Share > Add to Home Screen.

Dữ liệu tài chính vẫn lưu cục bộ trên trình duyệt/điện thoại.
Hãy dùng chức năng Backup JSON định kỳ.
